📋 Firebase Configuration Setup

🔗 How to Get Firebase Configuration:

  • Go to Firebase Console
  • Select your project or create a new one
  • Go to Project Settings ⚙️ → General tab
  • Scroll down to "Your apps" section and select your web app
  • Copy the config object from the "Firebase SDK snippet"
💡 Tip: If you don't have a web app, click "Add app" and select the web platform (</>) to create one.

📧 Email/Password Authentication Setup

🔧 Setup Steps:

  • Enable Provider: Go to Firebase Console → Authentication → Sign-in method
  • Enable Email/Password: Toggle on the Email/Password provider
  • Create Users: Go to Authentication → Users → Add user
  • Enter credentials: Add email and password for test users
💡 Tip: You can also enable "Email link (passwordless sign-in)" for a better user experience.

🔍 Google Sign-in Setup

🔧 Setup Steps:

  • Enable Provider: Go to Firebase Console → Authentication → Sign-in method
  • Enable Google: Toggle on the Google provider
  • Configure OAuth: Set up OAuth consent screen in Google Cloud Console
  • Add Domain: Include your domain in authorized domains
  • Web Client ID: Firebase will automatically configure this
⚠️ Important: For production apps, you'll need to configure the OAuth consent screen properly in Google Cloud Console.

🐙 GitHub Sign-in Setup

🔧 Setup Steps:

  • Create OAuth App: Go to GitHub → Settings → Developer settings → OAuth Apps
  • New OAuth App: Click "New OAuth App"
  • Configure App:
    • Application name: Your app name
    • Homepage URL: Your app URL
    • Authorization callback URL: https://your-project.firebaseapp.com/__/auth/handler
  • Get Credentials: Copy Client ID and Client Secret
  • Enable in Firebase: Go to Firebase Console → Authentication → Sign-in method
  • Configure GitHub: Enable GitHub provider and add your credentials
🔗 Callback URL: The callback URL format is always https://PROJECT_ID.firebaseapp.com/__/auth/handler

🔐 Domain Authorization Setup

⚠️ Why is this needed?

Firebase requires you to authorize domains that can use authentication to prevent unauthorized access.

🔧 Steps to authorize domain:

  1. Go to Firebase Console
  2. Select your project
  3. Go to Authentication → Settings
  4. Scroll down to "Authorized domains"
  5. Click "Add domain"
  6. Add your current domain
  7. Save the changes
⚠️ Important: Without this step, authentication will fail with "auth/unauthorized-domain" error.
